# Agent environment source repository

Read `.agents/skills/bootstrap-agent-env/SKILL.md` when bootstrapping or upgrading a target. Registry entries live in `.agents/registry.json`, and additional folders under `.agents/skills/` and `.agents/agents/<provider>/` deploy automatically. The Python installer provides conservative proposals; inspect and extend results for the target before finalizing. Run `python -m unittest discover -s tests -v` after modifying installer or runner code. For instruction or skill changes, read `.agents/skills/bootstrap-agent-env/references/evaluation-loop.md` and `references/grading.md`; compare fresh matched trials against the previous revision with agent traces, observed checks and separate blinded reviews. Treat agent summary alone as unverified. Home sync is `python -m agent_env home plan|sync`. Do not treat examples as safe deployment destinations.

# Agent environment source repository

Read `.agents/skills/bootstrap-agent-env/SKILL.md` when bootstrapping or upgrading a target. Registry entries live in `.agents/registry.json`, and additional folders under `.agents/skills/` and `.agents/agents/<provider>/` deploy automatically. The Python installer provides conservative proposals; inspect and extend results for the target before finalizing. Run `python -m unittest discover -s tests -v` after modifying installer or runner code. For instruction or skill changes, read `.agents/skills/bootstrap-agent-env/references/evaluation-loop.md` and test a fresh fixture against the previous revision; capture agent traces and actual checks separately from structural grading. Home sync is `python -m agent_env home plan|sync`. Do not treat examples as safe deployment destinations.
